# 🎯 Number Guessing Game (Python)

A simple command-line **Number Guessing Game** built with Python.

This was one of my early Python mini projects, created while learning core programming concepts. The game generates a random number between **1 and 100**, and the player must guess it using the hints provided after each attempt.

---

## 📌 Features

- 🎲 Random number generation
- 🔼 Higher/Lower hints
- 📊 Counts total attempts
- 💻 Simple command-line interface
- ⚠️ Basic exception handling

---

## 🛠️ Technologies Used

- Python 3
- `random` module

## 🎮 How to Play

- The computer randomly selects a number between **1 and 100**.
- Enter your guess.
- The program will tell you whether to guess **higher** or **lower**.
- Keep guessing until you find the correct number.
- The game displays the total number of attempts.
